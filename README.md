# 伊莫搶蛋地圖

伊莫「搶蛋大作戰」的 Windows 地圖工具，針對惡夢與混沌的 7 張候選地宮提供寶箱與蛋巢標記，支援地圖辨識、人物追蹤及透明覆蓋地圖。

**[下載最新版 EXE](https://github.com/FCL2025/aniimo-dungeon-map/releases/latest/download/AniimoDungeonMap.exe)** · [最新版本與其他附件](https://github.com/FCL2025/aniimo-dungeon-map/releases/latest)。

## 下載與啟動

1. 下載 `AniimoDungeonMap.exe`，放到你習慣的資料夾。
2. 直接執行 EXE，不需要安裝本應用。
3. 開啟伊莫；使用覆蓋地圖時，建議將遊戲設為視窗或無邊框視窗模式。

支援 Windows 10／11 64 位元；即時辨識與追蹤需要 Windows 10 1903 以上。若啟動時提示缺少 WebView2，請安裝 [Microsoft Edge WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/)。

## 選圖與篩選

側欄最上方的語言下拉選單可切換語言，支援簡體中文、English、日本語、한국어、繁體中文、Deutsch、Français、Español、Português、Русский、Indonesia、ไทย 與 Tiếng Việt。預設為繁體中文；選擇會自動保存，並同步主視窗與覆蓋地圖。切換語言會保留目前地圖、篩選、路線、縮放與追蹤狀態。

- 點左上角的側欄圖示，展開地圖與篩選設定。
- 在「選擇地圖」選取地宮編號，並選擇「惡夢」或「混沌」難度。滑鼠停在選單上時，可用滾輪切換。
- 勾選想看的蛋巢、金色寶箱、琉璃寶箱、首領、入口／出口或鑰匙等標記。「顯示房間模組補充點」預設開啟，可關閉以只查看地圖直接引用的候選點。
- 使用「圖示大小」調整標記尺寸；「全部顯示／全部隱藏」可一次切換所有類型。
- 勾選「顯示最佳路徑」，再選「路線 1」或「路線 2」。兩人使用相同的「顯示房間模組補充點」設定、各選一條路線，只開自己路線編號的琉璃候選與橙色支線鑰匙房。兩條路線可共用通道，但不分配相同寶箱或鑰匙房；主線候選、含鑰匙房候選的總數及門數都相差最多 1 個。金色寶箱仍自由查看，未納入分工。
- 入口與出口都可進出，可自動選起點或指定「從入口出發／從出口出發」，離開端依路線選擇。切換出發點不改變分配的寶箱。淺藍線與編號表示主線；橙色虛線是順路鑰匙房，有橙色鑰匙才走，沒有就跳過。開關、路線選擇與出發點會保存並同步到覆蓋地圖。
- 寶箱順序數字使用較大的圓形編號，便於在覆蓋地圖辨認；編號表示建議查看順序，不代表已開箱。

本機遊戲設定中，惡夢與混沌各列出相同的 7 張候選地圖：20032、20034、20035、20036、20037、20039、20040。手動選單與自動辨識只使用這 7 張；見 [地圖池查核](docs/難度地圖池查核.md)。

路線依底圖通道與候選座標規劃，階梯連接以淡金點線表示，實際上下層走法依現場地形。可達候選較少的地圖會減少兩邊的分配數量，避免重複開箱；候選數不保證當場生成或實際開箱數，詳見 [建議路線](docs/最佳路徑.md)。

「辨識」預設關閉，可直接按工具列「選擇出口」手動選圖。首次使用會自動開啟選圖介面；按遊戲的 M，以入口為中心選擇出口方向。有一張候選時直接套用；左側同時有 20036、20040 時，會顯示兩張地形縮圖、入口／出口位置，並標示 20036 的出口偏左下，供玩家比對。方向不確定時，可按「顯示全部地圖」查看七張候選。

手動選圖會立即關閉自動辨識，取消尚未完成的判斷。重新選擇後清除舊的人物位置，已開啟的追蹤會跟隨所選地圖繼續運作；取消選擇則保留目前地圖。

## 自動辨識與人物追蹤

1. 進入地宮後，開啟工具列的「辨識」，工具會自動尋找伊莫視窗。
2. 回到遊戲按 **M** 開啟地圖，等待辨識結果。可在側欄「辨識、追蹤設定與候選」查看目前狀態。
3. 確認選到正確地宮後，可關閉「辨識」，保留目前地圖。
4. 開啟「追蹤」，關閉遊戲的 M 地圖並回到遊玩畫面，即可嘗試定位人物。

使用 M 地圖時請保持預設、拉到最遠的視野，以使用門位與初始迷霧的快速辨識。地形與正門／側門的位置、距離及角度交叉確認後立即鎖定；正門被遮住時，使用初始地形與側門位置確認。門位無法使用時，完整比較七張地圖，要求地形分布夠廣且明顯勝過其他候選。線索不足時保留預覽，沒有固定 200 點限制。

七張候選地宮均已加入初始迷霧參考圖，包含 20036、20039，以及 20040 走廊尚未揭露的畫面，可用於稀疏起始地形的快速辨識。鎖定後停止地圖辨識，本場不再自動換圖；人物追蹤可獨立繼續。

手動選圖也能直接開啟「追蹤」。取得位置後，地圖會顯示薄荷綠人物標記與金色漣漪；主視窗右下角 **◎** 可將人物移到地圖中央。

**進入下一場或換地宮時，按「選擇出口」或覆蓋地圖的「重選」即可手動選圖。** 若要自動辨識，將「辨識」關閉再開啟即可清除上一場結果並重新辨識。

## 覆蓋地圖

點選工具列「地圖模式」，即可在遊戲上方開啟透明的小地圖視窗。主視窗可以最小化，篩選與人物位置仍會同步。

覆蓋地圖會依遊戲視窗大小調整：1920×1080 時約 590×590，2560×1440 時約 790×790，預設位於左下角。圖示大小預設為 150%，鑰匙標記額外放大 50%。

覆蓋地圖右上方提供「辨識」、「重選」與「追蹤」按鈕。「重選」會關閉辨識，直接在覆蓋視窗選擇出口，不需回到主視窗；選圖結果同步到主視窗並保存。未啟用辨識時，不顯示「手動選圖」狀態文字。

出口選單外圍保持透明，方向選項、入口與候選縮圖使用深色底，方便在明亮遊戲畫面上辨認；沒有候選的左上、左下隱藏並保留空位。選單開啟時暫時隱藏地圖；選好或按 ×／Esc 關閉後恢復顯示。

主視窗的「覆蓋大小」滑桿可在 50%–150% 間即時調整覆蓋視窗，按「重置大小」回到 100%。覆蓋視窗上的「大小」滑桿在放開後套用，避免滑桿跟著視窗移動。從左下角向右上放大，移動過的地圖仍以目前左下角為錨點；靠近遊戲邊界時會限制在遊戲畫面內。大小會自動保存並同步到兩個視窗。

- 按 **F1** 暫時隱藏覆蓋地圖，再按一次恢復；隱藏後可操作下方的遊戲畫面。
- 拖曳覆蓋視窗上方的移動圖示，調整地圖位置。
- 點右上角 **×**，或再次點主視窗的「地圖模式」，即可關閉覆蓋地圖。
- 遊戲鎖住滑鼠時，先按 **Alt** 顯示游標，再操作地圖。

## 常用操作

| 操作 | 功能 |
| --- | --- |
| 滑鼠滾輪 | 縮放地圖內容 |
| 主視窗「覆蓋大小」／「重置大小」 | 調整覆蓋視窗尺寸／回到 100% |
| 拖曳地圖 | 平移地圖 |
| 符合視窗 | 將整張地圖調整至可見範圍 |
| 置頂 | 讓主視窗顯示在其他一般視窗上方 |
| 左上角側欄圖示 | 展開或收合地圖與篩選設定 |
| 側欄底部「說明」 | 查看使用說明 |
| 側欄底部「DEBUG LOG」 | 開啟或關閉辨識診斷紀錄；預設關閉 |

## 常見問題

**找不到遊戲或無法辨識？**

確認遊戲已開啟且沒有最小化。在側欄「辨識、追蹤設定與候選」按「重新整理」並確認遊戲視窗，再回到遊戲開啟 M 地圖。也可使用「匯入 M 地圖截圖」進行辨識，或直接手動選圖。

工具會依遊戲程序及視窗類型選取遊戲主畫面，排除同一程序的 Qt 視窗，不依中文或英文視窗標題判斷。遊戲尚未建立主視窗時會提示先進入遊戲。DEBUG LOG 也會記錄選中的視窗 ID、標題、程序 ID 與視窗類型，方便追查擷取問題。

需要診斷時，先開啟側欄最下方的「DEBUG LOG」（預設關閉）。辨識開啟超過 5 秒仍未鎖定時，工具才會產生診斷 log，並在辨識設定中顯示路徑。預設位置為 `%LOCALAPPDATA%\local.aniimo.dungeonmap\logs\recognition.log`；請將此檔連同擷取預覽截圖與程式版本提供給開發者。log 會區分尚未收到畫面、未偵測到 M 地圖、辨識引擎仍在載入或比對、地形線索不足，以及候選尚待交叉確認；不儲存遊戲截圖。檔案達 1 MB 時保留前一份為 `recognition.log.1`。關閉開關後不再新增紀錄，既有檔案仍保留。

**人物沒有出現，或停在原地？**

確認地宮選擇正確、「追蹤」已開啟，且遊戲已關閉 M 地圖。若仍無法定位，展開「擷取預覽與範圍」，使用「框選小地圖」讓青框對準遊戲小地圖。灰色空心圈表示目前未取得新位置，保留的是最後一次定位。

**更新後需要重新設定嗎？**

選圖、難度、篩選、圖示大小與側欄狀態會自動保存。同一個 Windows 帳號更新程式或移動 EXE 後會沿用設定；更新前請先關閉舊版。

## 使用注意

- 地圖上的標記是候選位置，不代表每場都會生成，也不會自動標示寶箱是否已取得。
- 房間模組補充點以虛線外圈標示，是同房間模板推論出的候選位置，包含星法師首領；未必在當場生成。
- 辨識與追蹤仍是測試功能，迷霧、相似房間或擷取範圍不準確時可能無法定位；目前不辨識樓層。

開發與建置方式見 [開發文件](app/README.md)。
