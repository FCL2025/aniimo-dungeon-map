# 伊莫搶蛋地圖

桌面本地版：**[下載 Windows x64 EXE · 0.2.13 測試版](https://github.com/FCL2025/aniimo-dungeon-map/releases/download/v0.2.13/AniimoDungeonMap.exe)**。使用說明、第三方授權與 SHA-256 校驗檔見 [GitHub Release](https://github.com/FCL2025/aniimo-dungeon-map/releases/tag/v0.2.13)。不需要安裝本工具，地圖、點位、遊戲圖示與辨識引擎已內嵌。依使用者偏好，之後預設只輸出可直接開啟的本地應用，明確需要時才建立 ZIP。

0.2.13 精簡主視窗左上角：不再顯示「搶蛋大作戰」、地宮編號與「手動選圖」等狀態，側欄切換改為方形圖示按鈕，保留滑鼠提示與無障礙名稱。

0.2.12 將側欄恢復為只收合／展開、視窗尺寸不變，可自由調整長寬。人物位置恢復原本深色底盤與青綠圓圈，保留金色漣漪，並畫在寶箱等圖示上方。詳見 [側欄與人物標記調整](docs/側欄與人物標記調整.md)。

0.2.11 移除底部標記說明、清單與「新一場」。主視窗收合側欄時為正方形，展開時加寬側欄；重新開啟辨識即清除舊鎖定與候選。人物位置改成金色圓點與漣漪，畫在寶箱等圖示下方；失去定位後停止漣漪。詳見 [精簡介面與金色追蹤](docs/精簡介面與金色追蹤.md)。

0.2.10 將應用圖示與網頁 favicon 換成「珍藏·不朽晶鑽蛋」的粉鑽原圖，保留透明背景。Windows EXE、主視窗、覆蓋視窗及離線檢視器使用同一來源；重新打包也會保留。來源見 [圖示與地圖名稱](docs/圖示與地圖名稱.md)。

0.2.9 新增 **F1 隱藏／恢復覆蓋地圖**。先開啟「地圖模式」，遊戲在前景或主視窗最小化時，按 F1 即可暫時隱藏，再按恢復。隱藏時可點擊下方遊戲，位置、縮放、篩選及追蹤狀態保留；長按只切換一次。完全關閉地圖模式會釋放 F1。使用者提供的遊戲按鍵表未綁定 F1，F8 為一鍵快照。見 [快捷鍵驗證](docs/覆蓋地圖快捷鍵.md)。

0.2.8 將寶箱拆成「金色寶箱」「琉璃寶箱」，移除品質選單、低階寶箱與藍／紫鑰匙。地圖與難度選單可用滾輪切換，新增 75–250% 圖示大小滑桿，保存設定並同步覆蓋地圖。20037 鑰匙房的琉璃對應類型 2011「金色石棺」，與金色寶箱同為品質 5，改以物件類型區分。座標核對與驗證見 [寶箱分類與圖示大小](docs/寶箱分類與圖示大小.md)。

0.2.7 將「辨識」與「追蹤」拆成獨立開關。選定正確地宮後可關閉辨識，人物追蹤仍可獨立運作；也能手動選圖後直接追蹤。追蹤只載入目前地圖、優先處理最新畫面，僅追蹤時裁切小地圖後再編碼，最高每秒取樣 10 張。移除行走路徑，只顯示位置。使用方式與測試限制見 [獨立人物追蹤](docs/人物追蹤.md)。

發行資料夾與壓縮檔最多保留最新版及前兩版，目前為 0.2.13、0.2.12、0.2.11。之後每次驗證新版後執行 `scripts/prune_releases.ps1 -Apply`；不帶 `-Apply` 只列出清理清單，共用使用者設定不在清理範圍內。

0.2.6 將覆蓋小地圖的背景、工具列及按鈕改為透明，持續跟隨遊戲視窗移動；最小化時隱藏、還原後跟回。拖曳地宮編號可調整相對位置。修正未取得人物位置時 ◎ 顯示 loading 游標的問題，並快取底圖與標記、合併重繪和同步訊息，減少人物更新的繪圖成本。見 [覆蓋地圖與驗證](docs/覆蓋地圖.md)。

0.2.5 新增右上角「選單」，包含「加入搶蛋 Discord」與原本的「說明」。Discord 連結會交由預設瀏覽器開啟。左上角「收合側欄／展開側欄」可隱藏或顯示整個左側資訊欄，地圖會自動符合可用空間，重啟後保留收合狀態。

0.2.4 的「地圖模式」改成按下才開啟獨立覆蓋地圖，保留原主視窗。覆蓋視窗為 448 × 464 像素，1920 × 1080 遊戲畫面預設放在左側 (4, 496)，支援滾輪縮放、拖曳與人物位置估計；主視窗篩選與定位會同步。再按「地圖模式」或覆蓋視窗右上 × 關閉。提示 5 秒消失，鎖定狀態與「新一場」移至地宮編號旁。見 [覆蓋地圖與驗證](docs/覆蓋地圖.md)。

0.2.3 讓各版本共用同一個 Windows 帳號的設定，更新或移動應用資料夾後會保留篩選；首次啟動會從自身或同層舊版的 `Data` 匯入設定，請先關閉舊版。移除「陶罐」「其他搜刮點」的篩選選項與地圖標記。

0.2.2 改為工具列「辨識」開關，開啟即連接遊戲。初始迷霧也先跟隨第一名預覽；達 200 個吻合點（含）就鎖定本場，不再換圖，直到按「新一場」。遊戲在前景時按 M，會短暫加強取樣 2.4 秒；重複畫面略過、排隊最多 3 張、鎖定後不再搜尋 31 張地宮。可在側欄展開設定與候選。

0.2.0 新增「辨識地圖」：連接伊莫視窗或匯入 M 地圖截圖，部分地形不足以確認時保留候選、等待後續 M 地圖。確認地宮後嘗試以小地圖中心估計位置與軌跡。這是待實機校準的測試版，不保證迷霧或樓層變化下能定位。使用方法、驗證結果與需要的遊戲畫面見 [即時辨識測試版](docs/即時辨識測試版.md)。

0.1.1 移除參考圖檔名與括號描述，改用地宮編號；標記換成遊戲原始圖片。陶罐與其他搜刮點依遊戲設定共用寶箱圖示，首領使用星法師肖像。詳見 [圖示與地圖名稱](docs/圖示與地圖名稱.md)。

提供手動選圖、惡夢／混沌、獎勵與首領級幽黯星法師篩選、置頂、地圖模式、設定保存與測試版畫面辨識。需要 Windows 10/11 x64 與 Microsoft Edge WebView2 Runtime；即時擷取需要 Windows 10 1903 以上。其他電腦缺少 Runtime 時可依包內使用說明安裝。

設定與 WebView2 資料統一存於 `%LOCALAPPDATA%\local.aniimo.dungeonmap\WebView2`，不再綁定版本資料夾。建置、舊設定匯入與搬移說明見 [桌面版 README](app/README.md)；執行 `scripts/build_portable.ps1` 預設只輸出本地應用，明確需要 ZIP 時才加 `-Zip`。

## 離線網頁與解析資料

直接開啟 **[點位檢視器](exports/grab-eggs-data/index.html)**，切換地圖、惡夢／混沌、金色／琉璃寶箱與其他獎勵類型，也可調整圖示大小。不需要啟動伺服器。

原始圖片與並排對照保存在 [底圖圖庫](exports/grab-eggs-dungeons/index.html)。詳細資料關係、難度設定及限制見 [解析報告](docs/解析報告.md)。

工具範圍限定地城內：使用 `grab-eggs-dungeons` 的單張底圖，不載入額外分層貼圖。`grab-eggs` 是前期調查留下的外部地圖，不納入工具。怪物只顯示「首領級幽黯星法師」，其他開關為寶箱、蛋巢與鑰匙等；陶罐與其他搜刮點僅保留在原始解析資料。

## 判斷限制

- 圖庫是純地圖底圖，沒有把參考圖中的寶箱、蛋與其他圖示畫入原圖。
- 難度與候選座標已解析；獎勵群組會抽選，候選紀錄包含互斥與重疊項目，不是單場生成數。每場完整生成規則、伺服器抽圖池與即時角色定位尚未驗證。
- 部分房間引用缺少來源資料，模組補充點也是待核對推論；詳見解析報告。切換難度會篩選蛋巢模組，寶箱保留各候選群組。
- 自動分數是縮放後輪廓交集比與長寬比的一致度，不是辨識成功機率；尚非即時小地圖定位測試。
- 底圖與分層直接 alpha 疊合會呈現其他樓層變暗的效果。疊图僅供比對，未宣稱重現遊戲材質效果或所有顯示區域同時可通行。
- 腳本支援的是這個遊戲版本的緊湊 manifest 格式，不是通用 YooAsset 匯出器；版本結構不符會報錯。

## 重跑

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
$mapGroups = @('29999', '29999_1') + @(20031..20060 | ForEach-Object { [string]$_; [string]$_ + '_1' })
.\.venv\Scripts\python.exe scripts\extract_maps.py --groups $mapGroups --output exports\grab-eggs-dungeons
.\.venv\Scripts\python.exe scripts\build_previews.py exports\grab-eggs-dungeons
.\.venv\Scripts\python.exe scripts\compare_references.py
.\.venv\Scripts\python.exe -X utf8 scripts\parse_dungeon_data.py
```

`extract_maps.py` 支援 `--game`、`--version`、`--groups`、`--output`。
`--append` 只允許向相同 manifest 來源的提取紀錄追加群組；不存在的封包或解碼錯誤會記入失敗項目，不下載遊戲資源。

工具依賴：[UnityPy](https://github.com/K0lb3/UnityPy)、[Pillow](https://pillow.readthedocs.io/)。
