# 伊莫搶蛋地圖

**繁體中文** | [English](README.en.md)

伊莫「搶蛋大作戰」的 Windows 地圖工具，支援惡夢與混沌的 12 張地宮，提供寶箱／蛋巢／頭目標記、手動選圖、人物追蹤與透明覆蓋小地圖。地圖資料使用遊戲資源版本 3846247。

## 開始使用

1. 直接執行免安裝版 `AniimoDungeonMap.exe`；使用 ZIP 時請先完整解壓。
2. 在遊戲按 **M**，以入口為中心確認出口方向，再按工具的「選擇出口」。同方向有多張時，比對縮圖選擇；不確定可按「顯示全部地圖」。
3. 在側欄選擇難度與要顯示的標記，按「地圖模式」即可在遊戲上方顯示透明小地圖。
4. 進入下一場時，按小地圖上的「重選」重新選圖，不需回到主視窗。

需要人物位置時，選好地圖後開啟「追蹤」，再關閉遊戲的 M 地圖、回到遊玩畫面。

側欄「遊戲解析度」支援 16:9（1920×1080、2560×1440，選 1920×1080）與 21:9（3440×1440）。設定會保存，變更後會重設人物追蹤；覆蓋小地圖在 1440p 時預設約 790×790。

## 常用操作

| 操作 | 功能 |
| --- | --- |
| **F1** | 隱藏／恢復覆蓋小地圖 |
| 滑鼠滾輪／拖曳地圖 | 縮放／平移地圖 |
| 拖曳小地圖上方的移動圖示 | 調整覆蓋位置 |
| 「覆蓋大小」／「重置大小」 | 調整小地圖尺寸／恢復預設 |
| 出口選單 **×／Esc** | 取消選擇，恢復原本地圖 |
| 側欄最上方的語言選單 | 切換語言，同步到覆蓋小地圖 |

雙人分工時，勾選「顯示最佳路徑」，兩人使用相同的「顯示房間模組補充點」設定，各選路線 1、2，只開自己的編號寶箱。橙色虛線需有鑰匙才走，金色寶箱未納入分工。

## 使用須知

- 支援 Windows 10／11 x64；人物追蹤需要 Windows 10 1903 以上。若缺少 [WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/)，請先安裝。
- 遊戲建議使用視窗或無邊框模式；滑鼠被鎖住時先按 **Alt**。覆蓋地圖開啟後，主視窗可最小化。
- 程式會檢查 GitHub Releases；有新版時可下載新的免安裝版 EXE，替換檔案前請先關閉舊版。同一個 Windows 帳號會保留選圖、語言、路線與其他設定。
- 標記是候選位置，不保證每場生成，也不會自動記錄已開寶箱。寶箱使用原始圖示，以金色／淺藍色外框區分類型；較高的寶箱候選點加註 **2F**。人物追蹤可能受迷霧影響，目前不判斷人物所在樓層。

更多操作可查看側欄底部的「說明」。

側欄「說明」上方的「道具價值排名」收錄 24 種金色寶箱寶物、高級及初級脈衝與諧振能量石、金魄、鎏金鑰匙、紫魄，以及每單位重量價值嚴格大於 7,000 的 3 種紫色道具（鍍銀鑰匙與兩種中級能量石）。背包、攻擊增幅器、晶片和防護機體不列入。排名以 **25 格、70 kg、每件佔 1 格**計算：每格平均可分配 2.8 kg，**背包 CP＝售價 ÷ max(1, 重量 ÷ 2.8)**，由高到低、同值並列。2.8 kg 以下以每格售價比較，較重道具再按重量折算。

同區另有混沌船票每日購買與謎之蛋盒購買建議。若每場混沌成功獲得 300,000 蛋殼幣，買 10 張船票並完成 10 場時，每日現金淨額為 1,760,000；第 11～15 張只持平，從第 16 張起下降。時間較少時可參考 6 張的選項。蛋盒前 9 個每個 500,000、合計 4,500,000；因未取得開盒機率，9 個僅是價格級距預算建議。
