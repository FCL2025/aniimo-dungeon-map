# 0.2.3 設定保存與篩選驗證

0.2.3 將 WebView2 profile 固定至 `%LOCALAPPDATA%\local.aniimo.dungeonmap\WebView2`，保留原本的 localStorage key。首次啟動只匯入舊 profile 的 localStorage，不複製瀏覽器快取，也不修改舊資料。詳見 [桌面版 README](../app/README.md)。

「陶罐」與「其他搜刮點」不再提供開關或顯示標記。桌面版保留 31 張地圖、9 個類型、11,387 筆候選紀錄；完整解析資料仍保留原始分類。離線點位檢視器也移除這兩個選項及對應標記。

## 驗證結果

2026-09-26 使用正式 0.2.3 EXE 的相同 SHA-256 副本，在隔離資料夾以 `--hidden`、本機 CDP 和 agent-browser 驗證。`ANIIMO_TEST_DATA_DIR` 指向測試資料根目錄，沒有寫入使用者共用 profile，也沒有更動使用者正在執行的 0.2.2。

| 情境 | 結果 |
| --- | --- |
| 0.2.2 的旁置 Data → 同層 0.2.3 首次啟動 | 自動匯入篩選、地圖、難度、品質、補充點、置頂、地圖模式、擷取範圍 |
| 舊設定包含 pot / cache | 兩個已移除類型不出現在選項與地圖，其他勾選沿用 |
| 全部顯示／全部隱藏 | 只切換剩餘 9 類；全部隱藏後候選數為 0 |
| 變更設定並重啟 | 保留變更，空的勾選清單也不會重設為全部顯示 |
| 只複製 EXE 到不同位置，不攜帶 Data | 沿用共用 profile 的最新設定 |
| 原生置頂 | 升級後關閉、重啟後開啟，與儲存狀態一致 |
| 前端錯誤、設定與底圖載入錯誤 | 新版測試未出現錯誤 |

Rust 設定匯入測試 5 項通過，涵蓋新安裝／移動位置、一次匯入與保留原檔、目前資料夾優先、最近使用的舊資料優先、資料庫使用中拒絕複製並可重試。原有辨識邏輯 11 項測試通過。

機器可讀結果：`dist/preferences-verification-0.2.3.json`。測試截圖：`app/smoke-run-preferences-0.2.3/filters.png`。此測試驗證本機 Windows 與既有 WebView2，沒有測試另一個 Windows 帳號或新電腦。

## 重跑方式

```powershell
New-Item -ItemType Directory -Force app/smoke-run-preferences | Out-Null
rustc --test app/src-tauri/src/profile.rs -o app/smoke-run-preferences/profile-tests.exe
./app/smoke-run-preferences/profile-tests.exe
node --test scripts/tests/recognition-core.test.cjs
```

原生測試先複製 0.2.2 EXE 到隔離根目錄下的 `releases/AniimoDungeonMap-0.2.2-windows-x64-portable`，以 `--hidden` 啟動，僅對該程序設定 `WEBVIEW2_ADDITIONAL_BROWSER_ARGUMENTS=--remote-debugging-port=<測試埠>`。在介面設定地宮 20040、混沌、品質 4 以上、關閉補充點，勾選 `egg/chest/pot/cache/stellarys_boss/exit`，關閉置頂並開啟地圖模式；擷取範圍 key `aniimo-capture-regions-v1` 設成 `{"mini":[0.75,0.03,0.2,0.2],"map":[0.05,0.1,0.9,0.8]}`。

關閉舊測試 WebView2 後，依序執行以下三階段，使用 agent-browser 連接各階段測試 EXE 的 CDP。每階段前置 `window.preferenceTestPhase='<階段>';`，再以 `eval --stdin` 執行 [preferences-browser.js](../scripts/tests/preferences-browser.js)。

1. `upgrade`：將 0.2.3 放在隔離 releases 的同層版本目錄。設定 `ANIIMO_TEST_DATA_DIR` 到隔離根目錄下的 `shared`，首次啟動驗證匯入，再寫入另一組設定與全部隱藏。
2. `restart`：關閉測試程序後重新啟動同一個 0.2.3 EXE，維持同一個 `ANIIMO_TEST_DATA_DIR`，驗證重啟並改勾蛋巢及藍鑰匙。
3. `moved`：關閉測試程序後只複製 0.2.3 EXE 至另一個無 Data、無同層舊版的資料夾，仍使用同一個隔離共用資料根目錄，驗證保留第二階段的勾選。

完成後關閉 agent-browser 工作階段與隔離測試程序。測試資料不可放入發行包。
