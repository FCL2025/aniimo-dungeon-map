# 0.2.4 覆蓋地圖

按主視窗「地圖模式」才會開啟獨立的覆蓋地圖；主視窗保留，可調整設定或最小化。重新啟動程式不會自動開啟覆蓋地圖。再次按「地圖模式」，或按覆蓋地圖右上 × 都可關閉；關閉主視窗則一起結束。

## 尺寸與操作

使用者提供的 1920 × 1080 圖片，紅框外緣約為 x=2–451、y=494–961，450 × 468 像素。覆蓋視窗採 **448 × 464 實體像素**，預設位於遊戲可繪製區域左上角加 **(4, 496)**；有視窗邊框或在第二台螢幕時，也以遊戲內容區為基準。找不到遊戲時放在目前螢幕左側，並顯示短提示。拖曳地宮編號可以自行調整。

- 滾輪以游標位置縮放；拖曳地圖平移；⊞ 讓地圖符合視窗。
- 主視窗與覆蓋地圖同步地宮、難度、品質、類型與補充點。篩選／定位更新不會重設覆蓋地圖的縮放和平移；換地宮才重新符合視窗。
- 覆蓋地圖上的「辨識」與「新一場」會操作主視窗的同一份辨識狀態。
- 若遊戲鎖住滑鼠，先按遊戲提供的 Alt 顯示游標，再操作地圖。覆蓋範圍會接收滑鼠輸入，以支援縮放與點選。
- 建議使用遊戲視窗或無邊框視窗；獨佔全螢幕覆蓋尚未驗證。

主視窗的長提示改成不佔版面的浮動提示，5 秒後消失；完整辨識訊息仍可在側欄查看。本場狀態與「新一場」位於地宮編號旁，滑鼠停在狀態可查看吻合點數。相同本場的定位更新不會反覆延長提示。

## 人物位置

開啟「辨識」，在遊戲按 M，達 200 個吻合點鎖定地宮後，關閉 M 地圖回到遊玩畫面。程式比對左上小地圖與已鎖定地宮，以小地圖中心估計人物位置；成功時顯示青色圓標與軌跡。右下 ◎ 會將人物置中。超過 4 秒沒有新位置，會改成灰色空心「最後位置」；換地宮或按「新一場」會清除。

定位仍是畫面比對估計；迷霧、相似房間、小地圖縮放／旋轉、樓層與連續遊玩準確率仍需實機樣本驗證。使用者這次提供的圖片用於量測覆蓋區域，不能單憑這張外部遊玩畫面驗證地宮內的定位準確率。

## 實作與驗證

`src-tauri/src/overlay.rs` 非同步建立獨立的透明、置頂、無邊框 WebView2 視窗，使用實體像素尺寸；不將主視窗設為其 owner，因此主視窗最小化不應一併隱藏覆蓋地圖。關閉覆蓋視窗不觸發主視窗的擷取 shutdown。開啟時以遊戲 client rect 設定位置，之後可手動拖曳，尚未自動跟隨遊戲視窗移動。

前端 `overlay.js` 只接收顯示狀態與傳送操作；`desktop.js` 負責偏好保存與同步，`recognition.js` 和唯一的 Worker 仍在主視窗執行。原生行為參考 [Tauri WebviewWindowBuilder](https://docs.rs/tauri/2.10.3/tauri/webview/struct.WebviewWindowBuilder.html)。

測試使用隔離的 `ANIIMO_TEST_DATA_DIR`、隱藏正式 EXE 及本機 CDP，不改動使用者設定。

- 原生測試確認：按下才開啟第二個視窗、主視窗尺寸與位置保留、448 × 464 尺寸、無邊框置頂、篩選及定位跨視窗同步、滾輪縮放、人物置中、失去定位、新一場、兩種關閉方式與重新開啟。
- 透過正常視窗關閉訊息關閉主視窗，確認覆蓋視窗一併結束、程序正常退出。重啟後保留篩選，即使舊設定含有 compact／overlay 開啟旗標，也只顯示主視窗。
- 提示 5 秒後消失，消失前後地圖大小相同；連續位置同步不會重設縮放或延長提示。
- 真實 Worker 處理 4 張已知座標的合成小地圖，座標誤差均小於 0.6 底圖像素；空白畫面不產生位置。這是演算法回歸測試，不是實際遊戲定位精度承諾。
- Rust 10 項測試通過：覆蓋幾何 3 項、設定匯入 5 項、按鍵取樣 2 項；辨識核心 JavaScript 11 項測試通過。

結果在 `dist/overlay-verification-0.2.4.json`；截圖在 `app/smoke-run-overlay-0.2.4/`，其中的人物位置是受控測試資料。原生測試本機 DPI 為 100%；窄版面另檢查約 150% 縮放時的 CSS 可用寬度，其他 Windows DPI 設定仍待實機測試。

重跑命令：於 `app/src-tauri` 執行 `cargo test --release --locked`；根目錄執行 `node --test scripts/tests/recognition-core.test.cjs`。`scripts/tests/overlay-native-browser.js` 的五階段分別在主視窗／覆蓋視窗中以 agent-browser 執行；`scripts/tests/overlay-position-browser.js` 在允許本機檔案存取的前端測試頁執行。關閉／重開 WebView2 會替換 CDP 分頁，測試工具需重新取得分頁或固定主視窗分頁。
