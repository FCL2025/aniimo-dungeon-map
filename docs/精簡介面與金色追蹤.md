# 0.2.11 精簡介面與金色追蹤

## 介面

- 移除底部的「點選地圖上的標記」說明、標記清單、拖曳／滾輪提示與「新一場」按鈕。點選標記仍可框選，沒有下方資訊面板。
- 人物狀態文字只提供給輔助閱讀工具；取得位置後才顯示右下角 ◎ 置中按鈕，詳細追蹤訊息仍在側欄。
- 新使用者預設收合側欄；既有側欄設定保留。
- 收合時主視窗外框含標題列為正方形；展開時增加 280 個邏輯像素，不縮小地圖可用區域。原生視窗拖曳縮放停止 140 ms 後重新套用比例，並限制於目前螢幕工作區；最大化／最小化遵從系統行為。覆蓋地圖仍保持 448 × 464。

當時的收合與展開測試截圖已隨舊版 `dist` 測試產物清理。

## 辨識重設

重新開啟「辨識」會清除舊鎖定、候選清單、計時、待處理影格與人物位置，重建辨識 Worker。關閉辨識時仍保留目前選圖供獨立追蹤使用。

追蹤開關不會被辨識開關關閉；重新辨識時只重新初始化人物追蹤的狀態。舊 Worker 回傳值及切換前正在等待的擷取結果均不納入新一輪，避免舊結果重新鎖定上一張圖。

## 人物位置與繪圖順序

繪圖順序為：**底圖快取 → 人物金色圓點／漣漪 → 寶箱、蛋巢、首領等標記快取**。人物位置取消文字標籤，金色圓點使用 `#f5c95a`，亮色輪廓為 `#fff0b2`。兩道向外擴散的圓環每 1.6 秒循環，排程間隔 33 ms，實際更新率依 WebView 與螢幕更新而定。

1.5 秒未收到新位置時，停止漣漪並顯示灰色空心圈；清除追蹤、位置離開可視範圍、文件隱藏或系統要求減少動畫時不持續排程漣漪。底圖與標記僅在地圖、縮放、平移或篩選等變動時重建。

當時以**測試用人物座標**放在首領圖示上，檢查漣漪位於圖示後方；這不是實際遊戲定位畫面。該測試截圖已隨舊版 `dist` 測試產物清理。

- `cargo build --release --locked` 成功，輸出本地 0.2.11 EXE。
