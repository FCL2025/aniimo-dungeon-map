# PVE 單局撤離提醒（0.2.52）

PVE 側欄的「開始本局撤離提醒」只監看這一局。判斷中顯示旋轉圖示及「判斷中…（按下取消）」；連續兩張新畫面同時符合「撤離條件」標題及「搭乘蛋船安全撤離」文字後，播放一次指定 WAV 並停止擷取。完成後可再按同一按鈕開始下一局。重新啟動應用不會自動開啟提醒。

目前辨識範本僅支援**繁體中文遊戲介面**；工具本身的 13 種語言均有提示翻譯。開地圖、選單遮住文字或條件區域消失不視為完成。不需要先看到未完成畫面，達標後才啟動也能通知。遊戲最小化時暫停確認，還原後需要重新取得兩張符合的畫面；切到 PVP、手動取消或關閉應用會釋放提醒擷取。遊戲關閉／擷取失敗會顯示可重新啟動的錯誤狀態。

## 擷取與效能

- `evacuation.rs` 使用獨立的 Windows Graphics Capture 工作階段，沿用 `capture::is_game` 的 Aniimo.exe／UnityWndClass 篩選。不更動地圖辨識、人物追蹤的擷取設定。
- 支援的 Windows 版本設定 `MinUpdateInterval` 為 2 秒；回呼亦在像素處理前節流。不支援該屬性的 Windows 使用相同的回呼節流。系統送圖可能稍有抖動，允許提前 100 ms，避免略早到達的影格被丟掉而拖成 4 秒。
- 先在 GPU 裁切左側 HUD，再複製到 CPU。以 1080p 為基準為 `(24,235)` 起、`400×220` 像素；依遊戲視窗高度自動縮放，含視窗標題列修正，適用既有 16:9／21:9 解析度。
- `evacuation_vision.rs` 在原生執行緒比較字體的白色筆畫與深色描邊，不載入 OCR 模型或 OpenCV，不傳送 JPEG 到前端，也不保存／上傳畫面。
- 前端每秒讀取一次小型狀態物件；畫面判斷仍是約每 2 秒一次。原生層確認完成即播放並停止，不依賴主視窗可見性或瀏覽器音訊自動播放權限。

## 素材

`app/sounds/evacuation-complete.wav` 是使用者指定 `伊莫_SuperLucky.wav` 的原樣副本，SHA-256：`7c78292956516213af1c0017a14e2769dc3d05b891d5f44ac0fc754bf7fd3194`。48 kHz、16-bit、雙聲道 PCM，約 2.27 秒。由 Rust `include_bytes!` 內嵌，以 `PlaySoundW` 非同步播放；不依賴外部路徑或額外播放按鈕。音訊裝置拒絕播放時保留「已達標，但音效播放失敗」提示。

`app/evacuation-template.json` 由使用者提供的完成圖建立，保存筆畫／描邊對比點與來源雜湊。`scripts/build_evacuation_template.py <未完成圖> <完成圖>` 可重新產生；正常建置只讀已提交的範本。測試僅保存兩張左側 HUD 裁切，不含玩家名稱或 UID。

本次驗證：83 項 JavaScript、28 項 Rust 測試通過，原生流程八項檢查及 13 語系通過。最終 EXE 的頻率紀錄為 4,004 ms 內處理 2 張，平均 2,002 ms／張；該紀錄的未完成樣本處理 18 ms、完成樣本 9 ms，音效播放 API 回報成功。實際效能仍依硬體與視窗更新頻率而異。
